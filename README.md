# Conversor de PDF a Excel

Una herramienta automatizada en Python para extraer tablas estructuradas de archivos PDF y exportarlas a planillas de Excel (`.xlsx`). 

## Tecnologías utilizadas
* Python 3.11
* pdfplumber (Extracción de datos y lectura de coordenadas en PDF)
* pandas (Estructuración de datos y exportación)

## Cómo preparar el entorno local
1. Clonar el repositorio.
2. Crear un entorno virtual: `python -m venv venv`
3. Activar el entorno e instalar dependencias: `pip install pdfplumber pandas openpyxl`
